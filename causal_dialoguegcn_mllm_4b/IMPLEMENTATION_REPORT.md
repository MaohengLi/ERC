# 实现与检查汇报

## 完成范围

已在独立目录 `causal_dialoguegcn_mllm_4b` 中完成可训练、可保存、可恢复、可评估的
4B 版本。没有覆盖 `causal_erc_repro_4b` 或 `save/com_v9_3_4B` 的原始代码。

核心改造包括：

1. 用关系图注意力实现 DialogueGCN。边关系由源说话人、目标说话人和时间方向构成；
   默认仅允许过去向消息，避免当前话语读取未来话语。
2. 文本、音频、视频先投影到共同空间并进行话语级三模态交叉注意力，再进入图编码。
3. T/A/V/G 四个辅助头输出同一六分类概率空间。峰值定义为可靠性加权的非中性概率，
   因而音频和视频会直接参与心理学峰终记忆，而不是仅作为最终融合特征。
4. C1（历史驱动）路由至慢速 System 2，并动态扩大历史窗口；C2（峰终驱动）路由至
   快速 System 1。连续路由系数同时控制图状态融合和 LLM route token。
5. 五个特殊令牌分别注入 audio、video、text、graph 和 causal-route 表征。
6. Qwen3-4B 使用 NF4 双重量化和 LoRA；LLM 话语批次再按 micro-batch 切分，适配
   RTX 4070 Ti 12GB。
7. 总损失包含最终分类 CE、四分支辅助 CE 和有界 Soft-HGR 依赖损失。
8. 训练阶段的路由只使用上一 epoch、按对话 ID 保存的预测；dev/test 使用两遍推理，
   不使用真实标签生成因果类型。

## C1/C2 语义核对

原论文的定义是：C1 = language/history → emotion（历史语言造成当前情绪，慢速/System 2）；
C2 = emotion → language（已有情绪导致当前表达，快速/System 1）。工程中的固定判定为
`lambda_C1 < lambda_C2 → C1`，否则为 C2。因而若给出 `D_C1=0.62, D_C2=0.31`，算法会
选择 C2；这不是标签映射反了，而是这组距离值本身描述的是 C2。若要复现论文 Figure 1
中最后一句客服话语的 C1/neutral 结论，模型计算出的距离必须满足 `D_C1 < D_C2`。
该规则已加入回归测试，防止后续重构将 C1/C2 再次交换。

  输出 logits `[1,6]`、辅助 logits `[1,4,6]`，峰值显存约 4.35GB。

## 专家判断与实验边界

当前实现已构成结构闭环，适合作为下一阶段实验代码。真实单样本冒烟测试只能证明工程
可运行，不能代表模型效果；最终结论必须以完整训练的多个随机种子及加权 F1 为依据。
建议先跑一轮获得工程 baseline，再跑至少两轮确认因果路由被实际启用；正式对比应包含：
无因果路由、无峰终、无 DialogueGCN、双向图、无 Soft-HGR、纯 Causal-ERC 六组消融。
